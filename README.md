# 🎓 AI Smart Campus Assistant 🤖

A full-stack web application designed to digitalize and automate campus services using AI. This platform helps students access events, hackathons, canteen services, and interact with an AI assistant.

---

## 🚀 Features

### 👤 User Module
- Student Registration & Login
- Secure authentication system

### 📅 Events Management
- View upcoming campus events
- Admin can add new events

### 🏆 Hackathon Portal
- List of hackathons
- Admin can add hackathons with deadlines & prizes

### 🍔 Canteen System
- View menu items with pricing
- Admin can update canteen items

### 🤖 AI Assistant
- Answer student queries
- Provides guidance on:
  - Events
  - Hackathons
  - Canteen timings

### 🛠️ Admin Panel
- Add Events
- Add Hackathons
- Add Canteen Items
